# ai-12weeks

12-week roadmap to become job-ready in AI (ML + GenAI).

## Overview
A focused 12-week curriculum to build foundational machine learning skills, practical GenAI experience, and portfolio projects to demonstrate job readiness.

## Goals
- Learn core ML algorithms and evaluation.
- Gain practical experience with deep learning and generative models.
- Ship multiple projects and a capstone to showcase skills.
- Prepare for technical interviews and real-world ML tasks.

## Who this is for
- Engineers with basic Python skills.
- People aiming to transition into ML/GenAI roles or strengthen practical skills.

## Prerequisites
- Python 3.8+
- Basic probability & linear algebra
- Familiarity with git and the command line

## Setup
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## 12-Week Plan (high level)
Week 1 — Python tooling, data manipulation
- NumPy, pandas, matplotlib, EDA, feature engineering basics

Week 2 — Statistics & ML foundations
- Bias/variance, cross-validation, metrics, simple regression

Week 3 — Classical supervised learning
- Decision trees, random forests, gradient boosting (scikit-learn, XGBoost/LightGBM)

Week 4 — Unsupervised learning & pipelines
- Clustering, PCA, preprocessing pipelines, imbalanced data strategies

Week 5 — Deep learning foundations
- Neural nets, optimization, regularization (PyTorch)

Week 6 — CNNs & computer vision basics
- Image preprocessing, transfer learning, data augmentation

Week 7 — Sequence models
- RNNs, LSTMs, transformers (intro), time-series basics

Week 8 — Generative models
- VAEs, GANs overview, diffusion models introduction

Week 9 — Large Language Models & prompt engineering
- LLM usage, embeddings, retrieval-augmented generation (RAG)

Week 10 — MLOps basics
- Model packaging, reproducibility, evaluation, CI/CD for ML

Week 11 — Project week (mini projects)
- Build 2-3 small end-to-end projects (notebooks → deployed demo)

Week 12 — Capstone & interview prep
- Capstone project, tech interview practice, resume/portfolio polish

## Suggested Projects
- Tabular ML pipeline with cross-validation and model explainability
- Image classifier using transfer learning and a simple web demo
- Q&A chatbot with RAG using embeddings and an LLM
- Capstone: end-to-end app combining data pipeline, model, and deployment

## Tools & Libraries
- Python, pandas, scikit-learn, PyTorch, Hugging Face Transformers, FAISS/Annoy, Docker, GitHub Actions

## Resources
- Official docs: scikit-learn, PyTorch, Hugging Face
- Tutorials: fast.ai, official model hubs

## How to use this roadmap
- Treat weeks as flexible sprints: learn, implement, and document.
- Commit work to GitHub, write a short README per project, and produce a demo (colab, web app, or video).
